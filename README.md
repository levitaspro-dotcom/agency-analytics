# Агентство · Аналитика (Этап 1)

Ядро платформы: клиенты → проекты → магазины, роли и права доступа (главный
администратор / менеджер / клиент), единый финансовый модуль (выручка →
расходы Ozon → себестоимость → внешние расходы → налоги → прибыль) и главный
дашборд с постепенным раскрытием деталей. Раздел «ИИ-аналитик» и «Настройки →
ИИ» подключаются на следующем этапе без изменения этой части приложения —
дашборд и расчёты не зависят от наличия ИИ.

## Стек

Next.js 14 (App Router, TypeScript) + PostgreSQL + Prisma + NextAuth
(credentials). Деплой — Render (Web Service + Managed PostgreSQL).

## Локальный запуск

```bash
npm install
cp .env.example .env   # укажите реальный DATABASE_URL
npx prisma db push
node prisma/seed.js
npm run dev
```

## Структура доступа

Все проверки прав выполняются на сервере (`src/lib/authz.ts`), а не только
скрытием пунктов меню. Главный администратор — системная роль `SUPER_ADMIN`,
которая проходит проверку доступа к проекту без явного назначения и поэтому
сразу видит новые проекты.
